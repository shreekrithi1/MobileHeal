## Requirement

Date of birth is optional; the banner should be light yellow

## UX changes

- Add optional field **Date of Birth** (`date_of_birth`)
- **Banner Color**: default (#FFF4E5) → #FFF9C4

## Design notes

- New optional input “Date of Birth” is available; no alert is raised if left blank.
- Colour changes are applied live over the WebSocket; no app release is required.
- ⚠ Save button contrast is 3.91:1 (AA Large). WCAG AA needs 4.5:1 for normal text — consider a darker/lighter text colour.
- DataWatchdog: once live, 2 existing profiles will be missing name — those users get an in-app notification to complete it, and the team is alerted.
