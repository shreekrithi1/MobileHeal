# CR-12: on click on Save changes ,  go to Success screen

Requested by: You  
Created: 2026-10-08T14:52:35+00:00

## Requirement

on click on Save changes ,  go to Success screen

## UX changes

- **After Save**: default (stay) → success_screen

## Design notes

- New navigation: after a successful save the app shows a Success screen (“Profile saved”) with a “Back to profile” action. If required fields are missing, the user stays on the profile and sees the alert banner instead.
- ⚠ Save button contrast is 3.91:1 (AA Large). WCAG AA needs 4.5:1 for normal text — consider a darker/lighter text colour.

## Accessibility

| Element | Colours | Ratio | WCAG |
|---|---|---|---|
| Save button | #FFFFFF on #079455 | 3.91:1 | AA Large |
| Alert banner | #B54708 on #FFF4E5 | 4.99:1 | AA |

## User impact

0 of 3 existing profiles will be prompted; 0 alerts will clear.
