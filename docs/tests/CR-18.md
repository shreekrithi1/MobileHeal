# Test cases for CR-18

_Plain-English test cases. Steps marked 🤖 can run automatically in the preview._

## 1. City is required before a profile is complete

**Priority:** High  
**Objective:** Users who haven't provided City are prompted and can resolve it.  
**Preconditions:** Signed-in user on the Profile screen.  
**Test data:** Zip = `94105`, Nationality = `Sample Nationality`, Name = `Jane Doe`, Phone Number = `555-0100`, City = `Sample City`, Email = `jane@example.com`

| # | Step | Expected result |
|---|---|---|
| 1 | 🤖 Fill in the other required fields and leave City empty | The alert banner asks for City |
| 2 | 🤖 Look at the City field | City is highlighted as missing |
| 3 | 🤖 Tap the save button | The profile is not complete; the banner stays |
| 4 | 🤖 Enter a valid City | City is no longer highlighted |
| 5 | 🤖 Tap the save button | The banner disappears and the profile is saved |
