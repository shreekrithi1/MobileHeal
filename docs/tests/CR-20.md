# Test cases for CR-20

_Plain-English test cases. Steps marked 🤖 can run automatically in the preview._

## 1. Happy path: Save with name and email filled, Date of Birth empty

**Priority:** High  
**Objective:** User can save when required fields are filled and optional Date of Birth is empty; app stays on profile, shows success toast; button is green.  
**Preconditions:** Profile screen is open with editable fields.  
**Test data:** Name = `Ava Thompson`, Email = `ava.thompson@example.com`, Date of Birth = ``

| # | Step | Expected result |
|---|---|---|
| 1 | 🤖 Enter a valid name | Name is entered |
| 2 | 🤖 Enter a valid email | Email is entered |
| 3 | 🤖 Leave Date of Birth empty | Date of Birth remains blank |
| 4 | 🤖 Tap Save | Changes are saved; stay on profile |
| 5 | Check that no missing-fields banner appears | No error banner listing missing fields is shown (because all required fields are filled) |
