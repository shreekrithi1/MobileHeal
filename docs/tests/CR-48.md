# Test cases for CR-48

_Plain-English test cases. Steps marked 🤖 can run automatically in the preview._

## 1. Phone Number is required before a profile is complete

**Priority:** High  
**Objective:** Users who haven't provided Phone Number are prompted and can resolve it.  
**Preconditions:** Signed-in user on the Profile screen.  
**Test data:** Name = `Jane Doe`, Email = `jane@example.com`, Phone Number = `555-0100`

| # | Step | Expected result |
|---|---|---|
| 1 | 🤖 Fill in the other required fields and leave Phone Number empty | The alert banner asks for Phone Number |
| 2 | 🤖 Look at the Phone Number field | Phone Number is highlighted as missing |
| 3 | 🤖 Tap the save button | The profile is not complete; the banner stays |
| 4 | 🤖 Enter a valid Phone Number | Phone Number is no longer highlighted |
| 5 | 🤖 Tap the save button | The banner disappears and the profile is saved |
