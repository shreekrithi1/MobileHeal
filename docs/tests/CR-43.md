## 1. Restaurant Name is required before a profile is complete

**Priority:** High  
**Objective:** Users who haven't provided Restaurant Name are prompted and can resolve it.  
**Preconditions:** Signed-in user on the Profile screen.  
**Test data:** Menu Item = `Sample Menu Item`, Restaurant Name = `Sample Restaurant Name`, Quantity = `Sample Quantity`, Fulfillment Method = `Sample Fulfillment Method`, Name = `Jane Doe`, Email = `jane@example.com`

| # | Step | Expected result |
|---|---|---|
| 1 | 🤖 Fill in the other required fields and leave Restaurant Name empty | The alert banner asks for Restaurant Name |
| 2 | 🤖 Look at the Restaurant Name field | Restaurant Name is highlighted as missing |

| 4 | 🤖 Enter a valid Restaurant Name | Restaurant Name is no longer highlighted |
| 5 | 🤖 Tap the save button | The banner disappears and the profile is saved |
