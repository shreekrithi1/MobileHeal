# Test cases for CR-45

_Plain-English test cases. Steps marked 🤖 can run automatically in the preview._

## 1. Happy path save with all fields including Zip Code

**Priority:** High  
**Objective:** User can enter valid data for all fields, including the new optional Zip Code, and save successfully without navigation away from Profile  
**Preconditions:** App is on Profile screen with empty or editable fields  
**Test data:** Name = `Alex Johnson`, Email = `alex.johnson@example.com`, Date of Birth = `1990-01-15`, Town = `Springfield`, Zip Code = `01103`

| # | Step | Expected result |
|---|---|---|
| 1 | 🤖 Enter valid Name | Name is populated |
| 2 | 🤖 Enter valid Email | Email is populated |
| 3 | 🤖 Enter optional Date of Birth | Date of Birth is populated |
| 4 | 🤖 Enter optional Town | Town is populated |
| 5 | 🤖 Enter optional Zip Code | Zip Code is populated |
| 6 | 🤖 Tap Save | Changes are saved; stay on Profile; success banner appears with message |
| 7 | Verify no field errors are shown | No validation errors on any field |
