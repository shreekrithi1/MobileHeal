# Test cases for CR-42

_Plain-English test cases. Steps marked 🤖 can run automatically in the preview._

## 1. Happy path: Save with valid Name and optional fields; stay on Profile; success toast; correct button color

**Priority:** High  
**Objective:** Verify user can save when Name is provided and optional fields set; success feedback shows and screen stays on Profile; primary button color is correct.  
**Preconditions:** User is on the Profile screen.  
**Test data:** Name = `Alex Johnson`, Date of Birth = `1990-05-14`, Town = `Springfield`

| # | Step | Expected result |
|---|---|---|
| 1 | 🤖 Ensure Profile screen is open. | Profile screen is visible. |
| 2 | 🤖 Verify the primary button color matches design. | Primary button color is #079455. |
| 3 | 🤖 Enter a valid Name. | Name field contains the provided value. |
| 4 | 🤖 Enter an optional Date of Birth. | Date of Birth field contains the provided value. |
| 5 | 🤖 Enter an optional Town. | Town field contains the provided value. |
| 6 | 🤖 Tap Save. | Changes are saved; a success notification is shown; user remains on Profile screen. |

## 2. UX change: Email field is removed from the Profile screen and not referenced in validation

**Priority:** High  
**Objective:** Confirm the Email input no longer appears and the validation banner does not reference Email.  
**Preconditions:** User is on the Profile screen. Do not enter any data yet.  

| # | Step | Expected result |
|---|---|---|
| 1 | Verify that there is no Email field on the Profile screen. | Email field/label is not present anywhere on the screen. |
| 2 | 🤖 Attempt to save without entering any data. | A validation banner appears listing missing required fields. |
| 3 | Inspect the validation banner text. | Banner does not mention Email as missing. |

## 3. Negative: Missing required Name shows field error and banner mention for Name only

**Priority:** High  
**Objective:** Ensure Name is required and triggers both field-level and banner validation; banner should not list Email.  
**Preconditions:** User is on the Profile screen.  

| # | Step | Expected result |
|---|---|---|
| 1 | 🤖 Clear the Name field. | Name field is empty. |
| 2 | 🤖 Tap Save. | Validation occurs; Name field shows error; a banner lists missing Name. |
| 3 | Verify the validation banner content. | Banner lists only missing required fields and does not include Email. |

**Preconditions:** User is on the Profile screen.
