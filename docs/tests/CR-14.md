# Test cases for CR-14

_Plain-English test cases. Steps marked 🤖 can run automatically in the preview._

## 1. Nationality is required before a profile is complete

**Priority:** High  
**Objective:** Users who haven't provided Nationality are prompted and can resolve it.  
**Preconditions:** Signed-in user on the Profile screen.  
**Test data:** Nationality = `Sample Nationality`, Zip = `94105`, Phone Number = `555-0100`, Name = `Jane Doe`, Email = `jane@example.com`

| # | Step | Expected result |
|---|---|---|
| 1 | 🤖 Fill in the other required fields and leave Nationality empty | The alert banner asks for Nationality |
| 2 | 🤖 Look at the Nationality field | Nationality is highlighted as missing |
| 3 | 🤖 Tap the save button | The profile is not complete; the banner stays |
| 4 | 🤖 Enter a valid Nationality | Nationality is no longer highlighted |
| 5 | 🤖 Tap the save button | The banner disappears and the profile is saved |
