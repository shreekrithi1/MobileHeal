# Test cases for CR-30

_Plain-English test cases. Steps marked 🤖 can run automatically in the preview._

## 1. Happy path: Save with required fields only and City left blank (now optional)

**Priority:** High  
**Objective:** Verify that saving succeeds when Name and Email are filled and City is left blank after the rule change to optional.  
**Preconditions:** User is on Profile screen with editable fields.  
**Test data:** Name = `Alex Johnson`, Email = `alex.johnson@example.com`

| # | Step | Expected result |
|---|---|---|
| 1 | 🤖 Clear City so it is blank. | City field is empty. |
| 2 | 🤖 Enter valid Name. | Name is populated. |
| 3 | 🤖 Enter valid Email. | Email is populated. |
| 4 | 🤖 Tap Save. | Profile saves successfully; stays on Profile screen. |

## 2. Whitespace-only City is treated as empty and allowed

**Priority:** High  
**Objective:** Confirm that a whitespace-only City value does not block saving since City is optional.  
**Preconditions:** User is on Profile screen.  
**Test data:** Name = `Jamie Lee`, Email = `jamie.lee@example.org`, City Whitespace = `    `

| # | Step | Expected result |
|---|---|---|
| 1 | 🤖 Enter whitespace-only in City. | City field shows whitespace input. |
| 2 | 🤖 Enter valid Name and Email. | Name and Email populated. |
| 3 | 🤖 Tap Save. | Save succeeds; success banner and toast appear; remain on Profile. |

## 3. Regression: Missing required Name and Email show errors; City is not flagged

**Priority:** High  
**Objective:** Ensure only Name and Email are required and listed in the error banner; City should not be reported missing.  
**Preconditions:** User is on Profile screen with all fields editable.  

| # | Step | Expected result |
|---|---|---|
| 1 | 🤖 Clear Name, Email, and City. | All three fields are empty. |
| 2 | 🤖 Tap Save. | An error banner appears listing missing required fields Name and Email. Field-level errors show for Name and Email. |

## 4. Clear previously filled City and save

**Objective:** If the user had a City value (from when it was required), clearing it should be allowed and still save.  
**Preconditions:** User is on Profile screen and City currently has a non-empty value.  
**Test data:** Name Updated = `Taylor Brooks`, Email Updated = `taylor.brooks+1@example.com`

| # | Step | Expected result |
|---|---|---|
| 1 | 🤖 Clear City. | City becomes empty. |
| 2 | 🤖 Optionally update Name and Email with valid values. | Required fields are valid. |
| 3 | 🤖 Tap Save. | Save succeeds; success banner/toast; remain on Profile. |
